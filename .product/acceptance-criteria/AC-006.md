# AC-006: Non-spring ingredient shows no info

- **Status:** Deprecated
- **User Story:** [US-001](../user-stories/US-001.md)

## Criterion

On the recipes page, hovering the "Tomato" ingredient slot on the Mixed Salad recipe card shows exactly "No info available". Tomato is not listed on https://fogu.com/sos6/farming/crops_spring.html.

## Verification Method

Start the app, open the recipes page with "Owned only" unchecked, find the Mixed Salad card, and hover the pointer over its "Tomato" slot. Expected: the info text "No info available" is visible.

## Evidence

- **Checked:** Started the app with `python -m app`. The Cursor browser tool was unavailable ("Server not found"), so I drove a real headless Google Chrome through the DevTools protocol (`tmp/hover_check.py`, git-ignored). It opened `http://127.0.0.1:8000/?owned=false`, scrolled the Mixed Salad card's "1× Tomato" slot into view, moved the real mouse pointer onto it (`Input.dispatchMouseEvent` mouseMoved), listed every visible info text, and took a screenshot (`tmp/ac006_tomato_hover.png`).
- **Result:** Exactly one info text was visible: "No info available".
