# AC-007: Info hides when the pointer moves away

- **Status:** Deprecated
- **User Story:** [US-001](../user-stories/US-001.md)

## Criterion

The info text for an ingredient is not visible while the pointer is not over that ingredient. After hovering the "Turnip" slot on Turnip Salad and then moving the pointer away from it, the info text is no longer visible.

## Verification Method

Start the app and open the recipes page with "Owned only" unchecked. Before hovering, confirm no info text is visible on the Turnip Salad card. Hover its "Turnip" slot and confirm the info text appears, then move the pointer to an empty area of the page. Expected: the info text is not visible before hovering and disappears after the pointer moves away.

## Evidence

- **Checked:** Started the app with `python -m app`. The Cursor browser tool was unavailable ("Server not found"), so I drove a real headless Google Chrome through the DevTools protocol (`tmp/hover_check.py`, git-ignored). It opened `http://127.0.0.1:8000/?owned=false`, scrolled the Turnip Salad card into view with the pointer at the top-left corner, and listed every visible info text on the page and took a screenshot (`tmp/ac007_before.png`). It then moved the real mouse pointer onto the "1× Turnip" slot and listed visible info texts again. Finally it moved the pointer to an empty area left of the recipe grid (the element there was the page `BODY`), listed visible info texts, and took a screenshot (`tmp/ac007_after.png`).
- **Result:** Before hovering, no info text was visible anywhere on the page (empty list). While hovering the Turnip slot, exactly "Season: Spring; Purchase at Miguel's Mercantile, Happy Shoppe" was visible. After moving to the empty area, no info text was visible (empty list), and the screenshot shows the Turnip Salad card with no info box.
