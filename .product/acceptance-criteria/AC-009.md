## Verification Method

Start the app and open the recipes page with "Owned only" unchecked. For each ingredient in the table, find a recipe slot or slot popup list entry with that exact name and hover it. Expected: the visible info text matches the table exactly for all 22 ingredients.

## Evidence

- **Checked:** Started the app with `python -m app` and requested the recipes page with "Owned only" unchecked (`GET http://127.0.0.1:8000/?owned=false`, which is what the unchecked form submits). Searched the returned HTML for "Season:" and "Purchase at", and searched every file under `app/` for "Season", "Purchase at", and "crops".
- **Result:** The page loaded (HTTP 200, 516,373 characters, Turnip Salad present), but "Season:" and "Purchase at" appear nowhere in the page, and no file under `app/` contains them. There is no hover info UI yet (it belongs to US-001), so none of the 22 ingredients can show its expected text on hover. The method cannot be run as written until US-001 exists. No hover in a browser was attempted because the text is not in the page at all.
- **Outcome:** Fail

### Entry 2
