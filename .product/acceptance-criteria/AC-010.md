# AC-010: Crop info works with internet access off

- **Status:** Verified
- **User Story:** [US-002](../user-stories/US-002.md)

## Criterion

With the machine's internet access turned off, the app starts, and hovering the "Turnip" slot on the Turnip Salad recipe card shows exactly "Season: Spring; Purchase at Miguel's Mercantile, Happy Shoppe".

## Verification Method

Turn off or block the machine's internet access (local connections to the app must still work). Start the app, open the recipes page with "Owned only" unchecked, and hover the "Turnip" slot on Turnip Salad. Expected: the app starts without error and the info text "Season: Spring; Purchase at Miguel's Mercantile, Happy Shoppe" is visible.

## Evidence

- **Checked:** Internet access was not turned off; the subagent cannot turn off this machine's network. Started the app with `python -m app` with internet access on, requested the recipes page with "Owned only" unchecked (`GET http://127.0.0.1:8000/?owned=false`), and searched the HTML for "Season:" and "Purchase at".
- **Result:** The app started without error ("Application startup complete") and the page loaded with Turnip Salad present, but the info text "Season: Spring; Purchase at Miguel's Mercantile, Happy Shoppe" does not appear anywhere in the page. There is no hover info UI yet (it belongs to US-001). The method cannot be run as written: the hover does not exist, and the offline condition was not set up.
- **Outcome:** Fail
- **Recorded by:** subagent (US-002)
- **Date:** 2026-09-27

### Entry 2

- **Checked:** Orchestrator's own script `tmp/orch_verify.py offline`. Internet access was blocked for both processes involved, not for the whole machine. The app server process refused every socket connection to a non-loopback address. Chrome was started with `--proxy-server=http://127.0.0.1:9` (a dead proxy), so every non-loopback request fails. The script then started the app, opened `http://127.0.0.1:8000/?owned=false`, and hovered the Turnip Salad "Turnip" slot with the real pointer. Screenshot: `tmp/orch_offline_turnip_hover.png`.
- **Result:** The app started without error, and the page listed 266 recipes. The visible info text was exactly "Season: Spring; Purchase at Miguel's Mercantile, Happy Shoppe".
- **Outcome:** Pass
- **Recorded by:** orchestrator
- **Date:** 2026-09-27
