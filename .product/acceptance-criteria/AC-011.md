# AC-011: The running app never contacts fogu

- **Status:** Verified
- **User Story:** [US-002](../user-stories/US-002.md)

## Criterion

While the app starts, loads the recipes page, and shows hover info for ingredients, it sends no network requests to fogu.com.

## Verification Method

Watch the app's outgoing network requests (or intercept any attempt to reach fogu.com) while starting the app, loading the recipes page with "Owned only" unchecked, and hovering the "Turnip" slot on Turnip Salad. Expected: zero requests to fogu.com are observed, and the hover info still appears.

## Evidence

- **Checked:** Outgoing requests were not watched or intercepted. Started the app with `python -m app`, requested the recipes page with "Owned only" unchecked (`GET http://127.0.0.1:8000/?owned=false`), searched the HTML for "fogu.com", and searched every file under `app/` for "fogu", "requests", "urllib", "httpx", and "scrape_".
- **Result:** The page HTML does not contain "fogu.com", and no file under `app/` matches any of those terms. However, the hover info does not exist yet (it belongs to US-001), so the "hover info still appears" part cannot be observed. The outgoing traffic was not monitored, so "zero requests to fogu.com observed" was not observed either. The method cannot be run as written.
- **Outcome:** Fail
- **Recorded by:** subagent (US-002)
- **Date:** 2026-09-27

### Entry 2

- **Checked:** Orchestrator's own script `tmp/orch_verify.py online`. It hooked every outbound socket connection made by the app server process, and it recorded every request the browser sent through the DevTools `Network.requestWillBeSent` event. This covered app startup, loading `http://127.0.0.1:8000/?owned=false`, and hovering the Turnip Salad "Turnip" slot along with the other AC-001 to AC-009 targets.
- **Result:** The server made no connections to non-loopback addresses. The browser sent no requests to fogu.com, and none to any host other than 127.0.0.1:8000. Hover info still appeared: "Season: Spring; Purchase at Miguel's Mercantile, Happy Shoppe".
- **Outcome:** Pass
- **Recorded by:** orchestrator
- **Date:** 2026-09-27
