# AC-012: Recipes page works when stored crop info is removed

- **Status:** Verified
- **User Story:** [US-003](../user-stories/US-003.md)

## Criterion

With the stored crop info removed, the app starts, the recipes page lists the same recipes as it does with the info present, and hovering the "Turnip" slot on the Turnip Salad recipe card shows exactly "No info available".

## Verification Method

Note the recipe count shown on the recipes page with "Owned only" unchecked. Stop the app, move the stored crop info out of the project, and start the app again. Open the recipes page with "Owned only" unchecked and hover the "Turnip" slot on Turnip Salad. Restore the stored crop info afterward. Expected: the app starts without error, the page loads with the same recipe count, and the info text "No info available" is visible.

## Evidence

- **Checked:** Backed up `data/crops.json` to `tmp/us003_crops.json.bak` (same SHA-256 `A8AAEFEF…1AD1E2D4`). Made sure port 8000 was free, started the app with `python -m app`, and ran `tmp/us003_hover.py baseline`. That script drives headless Google Chrome over DevTools: it opens `http://127.0.0.1:8000/?owned=false`, reads the `.meta` line, moves the mouse pointer (real `Input.dispatchMouseEvent` mouse moves) onto the "Turnip" slot of the Turnip Salad card, and reads which info texts are visible. Then stopped the app (server, reloader, and launcher processes; port 8000 free again). Moved `data/crops.json` out of the project to `%TEMP%\us003_moved_crops.json` and confirmed it no longer existed in `data/`. Started the app again with `python -m app` and ran `tmp/us003_hover.py ac012`. Stopped the app, moved the file back, and compared SHA-256 hashes with the backup.
- **Result:** With the info present, the page showed "266 shown · 70 cookable now" (266 cards), and hovering Turnip showed "Season: Spring; Purchase at Miguel's Mercantile, Happy Shoppe". With the info removed, the app log showed "Application startup complete." with no errors, and `GET /?owned=false` returned 200 OK. The page showed "266 shown · 70 cookable now" (266 cards). Before the hover, no info text was visible; while hovering Turnip, the only visible info text was exactly "No info available" (screenshot `tmp/us003_ac012_turnip_hover.png`). The page threw no JavaScript exceptions. After restoring, `data/crops.json` has the same SHA-256 as the backup.
- **Outcome:** Pass
- **Recorded by:** subagent (US-003)
- **Date:** 2026-09-27
