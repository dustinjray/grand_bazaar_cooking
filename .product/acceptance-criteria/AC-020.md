# AC-020: Popup rows start collapsed

- **Status:** Verified
- **User Story:** [US-005](../user-stories/US-005.md)

## Criterion

When the popup for the "Turnip" slot on the Turnip Salad recipe card opens, no info text is visible for any row in the popup list.

## Verification Method

Start the app, open the recipes page with "Owned only" unchecked, and click the "Turnip" slot on Turnip Salad. Without clicking any row, look at the popup list. Expected: the rows "Turnip" and "Giant Turnip" are listed and no info text is visible in the popup.

## Evidence

### Entry 1

- **Checked:** Started the app with `python -m app` and ran `tmp/us005_verify.py`, which drives headless Google Chrome through the DevTools protocol with real `Input.dispatchMouseEvent` input. It loaded http://127.0.0.1:8000/?owned=false (Owned only unchecked), moved the mouse to (1,1), then clicked the "Turnip" slot button on the Turnip Salad card. Without clicking any row, it read every row in `#slot-dialog-list`: the name, and any rendered element with text outside the row's toggle button. It also read the dialog's rendered `innerText`. Screenshot: `tmp/us005_ac020.png`.
- **Result:** The dialog was open with the title "Turnip". It had 2 rows, "Turnip ×7" and "Giant Turnip", both `aria-expanded=false` with no visible info text. The dialog `innerText` contained neither "Season" nor "No info". No JS exceptions.
- **Outcome:** Pass
- **Recorded by:** subagent (US-005)
- **Date:** 2026-09-27
