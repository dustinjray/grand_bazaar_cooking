# AC-025: Non-spring row expands to no info

- **Status:** Verified
- **User Story:** [US-005](../user-stories/US-005.md)

## Criterion

In the popup for the "Vegetable A" slot on the Mixed Salad recipe card, clicking the "Tomato" row shows exactly "No info available".

## Verification Method

Start the app, open the recipes page with "Owned only" unchecked, click the "Vegetable A" slot on Mixed Salad, then click the "Tomato" row in the popup. Expected: the info text "No info available" is visible for that row.

## Evidence

### Entry 1

- **Checked:** Started the app with `python -m app` and ran `tmp/us005_verify.py` (headless Google Chrome via the DevTools protocol, with real `Input.dispatchMouseEvent` clicks). On a fresh load of http://127.0.0.1:8000/?owned=false (Owned only unchecked), it clicked the "Vegetable A" slot on Mixed Salad, then clicked the "Tomato" row in the popup (scrolled into view within the list first) and read the visible info text. Screenshot: `tmp/us005_ac025.png`.
- **Result:** The popup was titled "Vegetable A" with 20 rows. The Tomato row ("Tomato ×83") was `aria-expanded=true`, and its visible info text was exactly "No info available". No other row had visible info text. No JS exceptions.
