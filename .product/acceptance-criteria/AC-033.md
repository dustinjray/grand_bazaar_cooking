# AC-033: Non-crop popup row expands to no info

- **Status:** Verified
- **User Story:** [US-005](../user-stories/US-005.md)

## Criterion

In the popup for the "Any Milk" slot on the Asparagus Soup recipe card, clicking the "Milk" row shows exactly "No info available". Milk is not listed on any of fogu's four season crop pages.

## Verification Method

Start the app, open the recipes page with "Owned only" unchecked, click the "Any Milk" slot on Asparagus Soup, then click the "Milk" row in the popup. Expected: the info text "No info available" is visible for that row.

## Evidence

### Entry 1

- **Checked:** Ran `python tmp/us005b_verify.py`. It starts the app in-process (`app.main:app` under uvicorn on 127.0.0.1:8015) and headless Google Chrome (DevTools port 9415, temp profile), and drives Chrome with real `Input.dispatchMouseEvent` moves and clicks on http://127.0.0.1:8015/?owned=false (Owned only unchecked), starting each check from a fresh page load. "Visible info text" means a `.filler-info` element in a popup row that passes `checkVisibility()`, has nonzero height, and has text. Output is in `tmp/us005b_results.json`. It clicked the "Any Milk" slot on Asparagus Soup, then clicked the "Milk" row and listed the visible info texts. Screenshot: `tmp/us005b_ac033.png`.
- **Result:** The popup was titled "Any Milk" with rows "Buffalo Milk", "Milk", "Milk+", and "Buffalo Milk+". The Milk row was `aria-expanded=true`, and the only visible info text was exactly "No info available", on the Milk row. No JS exceptions.
- **Outcome:** Pass
