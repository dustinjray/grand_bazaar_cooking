# AC-036: Non-spring crop info works with internet access off

- **Status:** Verified
- **User Story:** [US-006](../user-stories/US-006.md)

## Criterion

With the machine's internet access turned off, the app starts, and hovering the "Pumpkin" slot on the Pumpkin Soup recipe card shows exactly "Season: Summer; Purchase at Miguel's Mercantile". Source: Pumpkin on https://fogu.com/sos6/farming/crops_summer.html.

## Verification Method

Turn off or block the machine's internet access (local connections to the app must still work). Start the app, open the recipes page with "Owned only" unchecked, and hover the "Pumpkin" slot on Pumpkin Soup. Expected: the app starts without error and the info text "Season: Summer; Purchase at Miguel's Mercantile" is visible.

## Evidence

### Entry 1

- **Checked:** Script `tmp/us006_verify.py offline`. Internet access was blocked for the processes involved, not for the whole machine.
  - **App:** the real `python -m app` was started with `PYTHONPATH=tmp/us006_netguard` and `US006_NET=offline`. Python then loads `tmp/us006_netguard/sitecustomize.py` in every process it starts, including uvicorn's reload worker. That file refuses every `socket.getaddrinfo` and `socket.connect` to a non-loopback host, and logs each attempt to `tmp/us006_net_offline.log`.
  - **Browser:** headless Google Chrome was started with `--proxy-server=http://127.0.0.1:9` (a dead proxy), with only loopback bypassed.
  - **Steps:** the script opened `http://127.0.0.1:8000/?owned=false` and hovered the Pumpkin Soup "Pumpkin" slot with the real pointer. Screenshot: `tmp/us006_offline_pumpkin_hover.png`.
  - **Proving the block:** it then ran a Python process under the same guard that tried to connect to fogu.com, and navigated Chrome to fogu's summer page.
- **Result:**
  - The guard was loaded in both app processes. The app started without error ("Application startup complete", with every request returning 200 except `/favicon.ico` at 404). "Owned only" was unchecked, and 266 recipe cards were listed.
  - The visible info text was exactly "Season: Summer; Purchase at Miguel's Mercantile".
  - The app made one socket connection, to 127.0.0.1, and no other lookups or connections.
  - The block worked: the guarded Python probe failed with "OSError: US-006 guard: internet off, refused getaddrinfo to fogu.com", and Chrome's fogu navigation failed with `net::ERR_PROXY_CONNECTION_FAILED`.
- **Outcome:** Pass
- **Recorded by:** subagent (US-006)
- **Date:** 2026-09-27

### Entry 2

- **Checked:** The orchestrator's own script, `tmp/orch_verify_us006.py offline`.
  - **Block:** in the app's process, before the app was imported, `socket.getaddrinfo`, `socket.socket.connect`, and `connect_ex` were replaced with a guard that refuses any non-loopback host. Headless Google Chrome was started with the dead proxy `--proxy-server=http://127.0.0.1:9`, with only loopback bypassed.
  - **Steps:** it started the app in-process with uvicorn, opened `http://127.0.0.1:8000/?owned=false` ("Owned only" read back as unchecked), and hovered the Pumpkin Soup "Pumpkin" slot with real mouse events. Afterwards, the same process tried to fetch fogu's summer page. Output: `tmp/orch_us006_offline.json`.
- **Result:** The app started without error, and the only visible info text was exactly "Season: Summer; Purchase at Miguel's Mercantile". The only network calls were to 127.0.0.1. The fogu fetch was blocked ("orchestrator guard refused getaddrinfo to fogu.com"), which shows the guard was effective.
- **Outcome:** Pass
- **Recorded by:** orchestrator
- **Date:** 2026-09-27
