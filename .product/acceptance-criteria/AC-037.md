# AC-037: The running app never contacts fogu for any season's info

- **Status:** Verified
- **User Story:** [US-006](../user-stories/US-006.md)

## Criterion

While the app starts, loads the recipes page, and shows hover info for ingredients, it sends no network requests to fogu.com.

## Verification Method

Watch the app's outgoing network requests (or intercept any attempt to reach fogu.com) while starting the app, loading the recipes page with "Owned only" unchecked, and hovering the "Pumpkin" slot on Pumpkin Soup. Expected: zero requests to fogu.com are observed, and the hover info "Season: Summer; Purchase at Miguel's Mercantile" still appears.

## Evidence

### Entry 1

- **Checked:** Script `tmp/us006_verify.py monitor`, with internet access on.
  - **App:** the real `python -m app` was started with `PYTHONPATH=tmp/us006_netguard` and `US006_NET=monitor`. Python then loads `tmp/us006_netguard/sitecustomize.py` in every process it starts, including uvicorn's reload worker. That file logs every `socket.getaddrinfo` and `socket.connect` to `tmp/us006_net_monitor.log` without blocking anything.
  - **Browser:** headless Google Chrome recorded every request the page sent, through the DevTools `Network.requestWillBeSent` event.
  - **Steps:** this covered app startup, loading `http://127.0.0.1:8000/?owned=false` ("Owned only" read back as unchecked), hovering the Pumpkin Soup "Pumpkin" slot, and the 61 AC-035 hovers and popup expands.
  - **Proving the monitor sees fogu:** afterwards, a Python process under the same guard connected to fogu.com.
- **Result:**
  - The guard was loaded in both app processes. The app made one socket connection, to 127.0.0.1, and no DNS lookups or connections to any other host. There were zero attempts to reach fogu.com.
  - The browser sent 6 requests, all to `http://127.0.0.1:8000`, and zero to fogu.com.
  - The hover info on Pumpkin Soup's "Pumpkin" slot was exactly "Season: Summer; Purchase at Miguel's Mercantile".
  - The monitor does record fogu traffic when it happens: the probe logged `getaddrinfo fogu.com` and a `connect` to 64.91.250.113.
- **Outcome:** Pass
- **Recorded by:** subagent (US-006)
- **Date:** 2026-09-27

### Entry 2

- **Checked:** The orchestrator's own script, `tmp/orch_verify_us006.py monitor`, with internet access on. In the app's process, every `socket.getaddrinfo`, `socket.socket.connect`, and `connect_ex` call was logged without blocking. Chrome's page requests were recorded through the DevTools `Network.requestWillBeSent` event. This covered app startup, loading `http://127.0.0.1:8000/?owned=false`, hovering the Pumpkin Soup "Pumpkin" slot, and all 61 AC-035 hovers and popup expands. Output: `tmp/orch_us006_monitor.json`.
- **Result:** The app's network log contained only `getaddrinfo 127.0.0.1` and `connect 127.0.0.1`. The browser sent 6 requests, all to `http://127.0.0.1:8000`. There were zero requests to fogu.com. The Pumpkin hover showed exactly "Season: Summer; Purchase at Miguel's Mercantile".
- **Outcome:** Pass
- **Recorded by:** orchestrator
- **Date:** 2026-09-27
