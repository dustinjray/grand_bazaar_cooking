# AC-043: Fish info works with internet access off

- **Status:** Verified
- **User Story:** [US-008](../user-stories/US-008.md)

## Criterion

With the machine's internet access turned off, the app starts, and hovering the "Salmon" slot on the Poke recipe card shows exactly "Seasons: Autumn, Winter; Weather: All weather; Locations: Mountain Hilltop; Rod: Gold".

## Verification Method

Turn off or block the machine's internet access (local connections to the app must still work). Start the app, open the recipes page with "Owned only" unchecked, and hover the "Salmon" slot on Poke. Expected: the app starts without error and the info text "Seasons: Autumn, Winter; Weather: All weather; Locations: Mountain Hilltop; Rod: Gold" is visible.

## Evidence

- **Checked:** The machine's NIC was not turned off. Internet was blocked for the two processes in the check: `tmp/us008_app.py` started `python -m` equivalent uvicorn on 127.0.0.1:8000 with every non-loopback `socket.connect` refused, and headless Chrome used `--host-resolver-rules=MAP fogu.com 0.0.0.0,MAP *.fogu.com 0.0.0.0` (`tmp/us008_hover.py salmon`). A dead `--proxy-server=http://127.0.0.1:9` was tried first but also blocked localhost on this Chrome, so it was not used. Opened `http://127.0.0.1:8000/?owned=false` and hovered the Poke "Salmon" slot with a real `Input.dispatchMouseEvent` mouse move.
- **Result:** The app log showed "Application startup complete." with no errors. The page meta was "266 shown · 70 cookable now". The only visible info text while hovering Salmon was exactly "Seasons: Autumn, Winter; Weather: All weather; Locations: Mountain Hilltop; Rod: Gold".
- **Outcome:** Pass
- **Recorded by:** subagent (US-008)
- **Date:** 2026-09-27

### Entry 2

- **Checked:** Orchestrator's own script `tmp/orch_verify_us008.py offline`. The app server process refused every non-loopback socket. Chrome mapped `fogu.com` to `0.0.0.0`. Started the app, opened `http://127.0.0.1:8000/?owned=false`, and hovered the Poke "Salmon" slot with a real pointer move.
- **Result:** The page meta was "266 shown · 70 cookable now" with Owned only unchecked. The visible info text was exactly "Seasons: Autumn, Winter; Weather: All weather; Locations: Mountain Hilltop; Rod: Gold". Python net log had only 127.0.0.1.
- **Outcome:** Pass
