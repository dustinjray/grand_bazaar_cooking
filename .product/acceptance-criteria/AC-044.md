# AC-044: The running app never contacts fogu for fish info

- **Status:** Verified
- **User Story:** [US-008](../user-stories/US-008.md)

## Criterion

While the app starts, loads the recipes page, and shows hover info for a named fish, it sends no network requests to fogu.com.

## Verification Method

Watch the app's outgoing network requests (or intercept any attempt to reach fogu.com) while starting the app, loading the recipes page with "Owned only" unchecked, and hovering the "Salmon" slot on Poke. Expected: zero requests to fogu.com are observed, and the hover info still appears.

## Evidence

- **Checked:** `tmp/us008_app.py` logged every outbound `socket.connect` / `connect_ex` while the app started. `tmp/us008_hover.py salmon` (and later `all`) enabled Chrome DevTools `Network.requestWillBeSent` while loading `http://127.0.0.1:8000/?owned=false` and hovering the Poke "Salmon" slot. Also searched every file under `app/` for "fogu", "requests", "urllib", "httpx", and "scrape_".
- **Result:** The app connect log recorded only `connect ('127.0.0.1', 51736)`. The browser sent six requests, all to 127.0.0.1:8000 (`/?owned=false`, `/static/styles.css`, `/static/app.js`, `/static/cook.js`, `/static/recipes.js`, `/favicon.ico`). Zero requests to fogu.com. No file under `app/` matches those search terms. The Salmon hover text still appeared: "Seasons: Autumn, Winter; Weather: All weather; Locations: Mountain Hilltop; Rod: Gold".
- **Outcome:** Pass
- **Recorded by:** subagent (US-008)
- **Date:** 2026-09-27
