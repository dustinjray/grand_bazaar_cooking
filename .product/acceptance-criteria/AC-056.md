# AC-056: Recipes page works when stored fish info is removed

- **Status:** Verified
- **User Story:** [US-010](../user-stories/US-010.md)

## Criterion

With the stored fish info removed, the app starts, the recipes page lists the same recipes as it does with the info present, and hovering the "Salmon" slot on the Poke recipe card shows exactly "No info available".

## Verification Method

Note the recipe count shown on the recipes page with "Owned only" unchecked. Stop the app, move the stored fish info out of the project, and start the app again. Open the recipes page with "Owned only" unchecked and hover the "Salmon" slot on Poke. Restore the stored fish info afterward. Expected: the app starts without error, the page loads with the same recipe count, and the info text "No info available" is visible.

## Evidence

- **Checked:** Backed up `data/fish.json` (SHA-256 `78de8dcf…9865a1`). Started the app as a fresh `uvicorn` process serving `app.main:app` on a free loopback port (8000 was not required). Ran `tmp/us009_verify.py`, which drives headless Google Chrome over the DevTools protocol with real `Input.dispatchMouseEvent` mouse moves. On `/?owned=false` it read the `.meta` line and hovered the "Salmon" slot on Poke. Then it stopped the app, moved `data/fish.json` out of the project, started a new app process, opened `/?owned=false` again, and hovered the same slot. Screenshot: `tmp/us009_ac047_salmon_hover.png`, checked by eye. Restored `data/fish.json` afterward and compared SHA-256 with the backup.
- **Result:** With the info present, the page showed "266 shown · 70 cookable now" (266 cards), Owned only was unchecked, and hovering Salmon showed "Seasons: Autumn, Winter; Weather: All weather; Locations: Mountain Hilltop; Rod: Gold". With the info removed, the app log included "Application startup complete." and `GET /?owned=false` succeeded. The page showed "266 shown · 70 cookable now" (266 cards). Before the hover, no info text was visible; while hovering Salmon, the only visible info text was exactly "No info available". No JavaScript exceptions. After restore, `data/fish.json` had the same SHA-256 as the backup (45 species).
- **Outcome:** Pass
