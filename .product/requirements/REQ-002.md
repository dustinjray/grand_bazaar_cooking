# REQ-002: Crop info comes from locally stored data

- **Status:** Active

## Description

The crop info (seasons, seed stores, and rare varieties) is collected once from fogu's four season crop pages and kept in the project:

- Spring: https://fogu.com/sos6/farming/crops_spring.html
- Summer: https://fogu.com/sos6/farming/crops_summer.html
- Autumn: https://fogu.com/sos6/farming/crops_autumn.html
- Winter: https://fogu.com/sos6/farming/crops_winter.html

The running app never contacts fogu to show crop info.
