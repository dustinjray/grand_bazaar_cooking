# REQ-002: Crop info comes from locally stored data

- **Status:** Active

## Description

The spring crop info (season, seed stores, and rare varieties) is collected once from fogu's spring crops page (https://fogu.com/sos6/farming/crops_spring.html) and kept in the project. The running app never contacts fogu to show crop info. Only spring crops are covered for now.
