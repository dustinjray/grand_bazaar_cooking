# REQ-004: Show fish info for ingredients on the recipes page

- **Status:** Active

## Description

The recipes page shows a short fish catch-info text for ingredients in the same two places as crop info.

- **Recipe cards:** hovering a named-fish ingredient slot (for example "1× Salmon" on Poke) shows that fish's info text. The text is hidden when the pointer is not over the slot.
- **Slot popup list:** clicking a fish row expands it, showing that fish's info text beneath its name, slightly indented. Clicking the row again collapses it. Rows open and close independently. All rows start collapsed every time the popup opens. Hovering a row in the popup shows no info.

Group slots such as "Fish A" still show "No info available".

The info text for a listed fish follows these rules. Values come from the Fish Encyclopedia tables on https://fogu.com/sos6/activities/fishing.html.

- Always: seasons, weather, and locations.
- Time of day only when that page gives one (Shining Fish: 12:00 pm to 5:00 pm). Otherwise omit time entirely.
- Rod level when that page gives one (including "All").
- No sell profit and no size (small/medium/large/guardian).
- Page typos are corrected (for example "All Season" becomes "All seasons").

Wording:

- Seasons: "All seasons" when the page says All Season(s); otherwise comma-separated in page order.
- Weather: "All weather" and "Any weather" are kept; other phrases are lowercased after the first word, with commas between tokens (for example "Not sunny, not cloudy", "Sunny, cloudy", "Rainy, stormy", "Not stormy, not heavy rain", "Heavy rain, stormy", "Sunny, no wind").
- Locations: comma-separated, page order, without a time parenthetical.
- Time, when present: "Time: 12:00 pm to 5:00 pm".
- Rod: the page's rod level, including "All".

Examples:

- Salmon: "Seasons: Autumn, Winter; Weather: All weather; Locations: Mountain Hilltop; Rod: Gold"
- Eel: "Seasons: Autumn, Winter; Weather: Not sunny, not cloudy; Locations: Gabriel's House, Zephyr Town; Rod: Copper"
- Shining Fish (if it appears as an item): "Seasons: Autumn; Weather: Sunny, no wind; Locations: Mountain Hilltop; Time: 12:00 pm to 5:00 pm; Rod: Orichalcum"

Ingredients that are not a listed fish and not a spring crop still show "No info available" (for example Fish Cake and Tomato).
