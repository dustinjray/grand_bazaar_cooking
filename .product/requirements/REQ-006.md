# REQ-006: Missing fish info never breaks the recipes page

- **Status:** Active

## Description

If an ingredient has no fish info, or the stored fish info is missing or unreadable, the app does not crash: the recipes page still loads and works normally, and those ingredients show "No info available" (or their crop info, if they have it).
